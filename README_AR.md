# Abderrahmen ch. — Racing 3D\n\nلعبة سباقات ثلاثية الأبعاد قابلة للعب على الهاتف، بمنظور قمرة القيادة، تحكم لمس، سيارات مرور، إضاءة وضباب ومسافة سباق 5 كم.\n\n## النشر\n1. ارفع جميع الملفات إلى جذر مستودع GitHub نفسه الذي يحتوي على README.md.\n2. احفظ التغييرات في فرع main.\n3. افتح Settings → Pages، اختر Deploy from a branch ثم main و /(root)، واضغط Save.\n4. افتح رابط Pages في Chrome. من قائمة ⋮ اختر Install app أو Add to Home screen.\n\nملاحظة: اللعبة تستخدم مكتبة Three.js من CDN، لذا تحتاج اتصال إنترنت عند التحميل الأول. الأداء يعتمد على الهاتف.
